Este es el código de soporte para “Descubre Java moderno”, un curso que se imparte cada dos meses a los suscriptores de [O’Reilly](https://www.oreilly.com/live-training/).

Todos los ejemplos están diseñados para ejecutarse con Java 21.

## Actualizar derechos de autor

`mvn validate license:format`

## Actualizar versiones y complementos

`mvn versions:display-dependency-updates versions:display-plugin-updates`
