これは、[O’Reilly](https://www.oreilly.com/live-training/)のサブスクライバー向けに2ヶ月ごとに開催される講座「Modern Javaを発見しよう」のサポートコードです。

すべての例はJava 21を使用して実行することを想定しています。

## 著作権情報の更新

`mvn validate license:format`

## バージョンとプラグインのアップグレード

`mvn versions:display-dependency-updates versions:display-plugin-updates`
